# 全穀雜糧與精製澱粉代謝差異

## 1. 概念核心原理
「全穀雜糧類」是人類傳統主食的主要熱量來源。依據 [[每日飲食指南手冊-國健署]] 與 [[我的餐盤手冊-國健署]] 的定義，穀物依照加工精製程度，其體內代謝生理途徑具有截然不同的表現：

### 1.1 穀物結構與加工流失
完整的穀粒由三部分組成：
1. **麩皮 (Bran)**：外層保護層，富含非水溶性與水溶性膳食纖維、B 群維生素、鎂、鋅等微量礦物質。
2. **胚芽 (Germ)**：核心萌芽區，富含維生素 E、多不飽和脂肪酸、抗氧化多酚。
3. **胚乳 (Endosperm)**：內部最大體積部分，主要成分幾乎純為澱粉（支鏈與直鏈澱粉）與少量蛋白質。

* **精製澱粉（如白米、白吐司、油麵、蔥油餅麵糰）**：碾磨加工時去除了麩皮與胚芽，僅保留胚乳。營養密度極低，消化酶可快速分解釋放葡萄糖。
* **未精製全穀雜糧（如糙米、燕麥粒、紫米、地瓜、南瓜、紅藜）**：保留了完整的三層結構，植物細胞壁天然減緩水解。

## 2. 代謝生理與外食健康對比

| 評估維度 | 未精製全穀雜糧 | 精製白澱粉與加工麵食 |
| :--- | :--- | :--- |
| **升糖指數 (GI) & GL** | 低至中等，血糖曲線平緩升降 | 高 GI，誘發劇烈 [[胰島素阻抗與早餐升糖反應|血糖暴衝與胰島素峰值]] |
| **飽足感維持時間** | 長（纖維吸水膨脹，延緩胃排空） | 短（1.5~2 小時觸發反應性飢餓） |
| **微量營養素保留** | 保留 70% 以上 B 群、鎂、鉀、維生素 E | 流失 80% 微量元素，易引發隱性飢餓 |
| **腸道菌相與短鏈脂肪酸** | 提供益生元，發酵產生丁酸與乙酸抗發炎 | 缺乏發酵受質，加重腸道發炎反應 |

## 3. 外食早餐的主食選擇指引
國健署明確規定：**「每日主食至少 1/3 應為未精製全穀雜糧」**。
在早餐店落實的具體技巧：
* 將白吐司置換為**原片燕麥**或**全麥吐司**。
* 以小烤地瓜（約 80~100g，約半碗飯份量）取代鐵板麵或可頌麵包。
* 注意避開 [[磨粉澱粉與液態糖吸收動力學|磨粉全穀地雷]]（如五穀粉沖泡飲因研磨破壁，失去緩慢吸收優勢）。
