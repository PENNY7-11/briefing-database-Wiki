# 磨粉澱粉與液態糖吸收動力學

## 1. 概念核心原理
許多人認為「五穀粉」、「燕麥飲」或「綠拿鐵」是極為健康的養生早餐，但從消化生理與吸收動力學（Absorption Kinetics）來看，**食物的物理形態對血糖反應具有決定性影響**。

### 1.1 研磨破壁效應 (Milling & Particle Size Effect)
* **天然全穀**：含有完整的種皮、糊粉層與胚乳細胞壁結構，消化酵素（如唾液與胰澱粉酶）需要時間逐層水解，胃排空慢、升糖曲線平緩。
* **研磨成粉（五穀粉/沖泡粉）**：
  * 機械粉碎徹底破壞了植物細胞壁與物理屏障。
  * 表面積呈幾何級數增加，使水分與水解酵素能以極高速度滲透。
  * 雖然營養成分標籤看似「全穀雜糧」，但其體內消化吸收速率已接近精緻糖類，引發劇烈的 [[胰島素阻抗與早餐升糖反應|血糖飆升]]。

### 1.2 液態糖與果糖短路
* 綠拿鐵、果汁在破壁攪打過程中，將大量不可溶性纖維切碎，蔬果中的果糖以游離液態形式存在。
* 液態糖幾乎不需在胃中停留研磨，迅速進入小腸吸收直奔門靜脈，高濃度果糖直接在肝臟進行脂肪合成（De Novo Lipogenesis），加重脂肪肝風險。

## 2. 常見迷思與臨床實證
在 [[你早餐吃對了嗎-鄧雯心醫師]] 的案例分析中：
* **NG 組合**：饅頭 + 五穀粉沖泡飲 + 燕麥片，醣類比例高達 74%，屬於「磨粉吸收催化型的爆醣組合」。
* **NG 綠拿鐵**：地瓜 + 水果 + 綠拿鐵，醣類高達 94%，缺乏油脂與蛋白質阻擋吸收。

## 3. 實用替代對策
1. **以原型取代粉末**：選用需要咀嚼的「原片大燕麥粒（Rolled Oats）」取代即溶沖泡粉。
2. **減量並加阻隔**：若飲用五穀粉，應減半份量（如 15g），並以無糖豆漿或添加起司、堅果沖泡，利用健康油脂與蛋白質降低消化酵素滲透速度。
3. **綠拿鐵的黃金菜果比**：嚴格維持**蔬菜：水果 = 3 : 1**，並額外搭配水煮蛋或植物性蛋白質。
