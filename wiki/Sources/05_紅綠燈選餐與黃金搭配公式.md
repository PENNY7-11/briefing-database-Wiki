# 來源摘要：05 外食族「紅綠燈選餐法」與 500 大卡黃金搭配公式

## 核心要點歸納
1. **紅綠燈選餐框架**：
   - 🟢 綠燈：原型食物、優質高蛋白（豬里肌、蛋、無糖豆漿）、複合碳水。
   - 🟡 黃燈：原味/蔬菜蛋餅、烤吐司夾蛋，可透過改裝降階為綠燈。
   - 🔴 紅燈：鐵板麵、炸物卡啦雞、油條、大冰奶。
2. **500 大卡黃金早餐公式**：
   - 複合低 GI 碳水 (40%) + 蛋白質 $\ge 20\text{g}$ (30%) + 優質脂肪 (30%) + 無糖高纖飲品。
3. **改裝救命點法 (Custom Order Hacks)**：
   - 「完全去沙拉醬 / 美乃滋」
   - 「煎台少油」
   - 「大冰奶換無糖高纖豆漿或黑咖啡」
