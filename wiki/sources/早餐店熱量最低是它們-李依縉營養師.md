# 早餐店熱量最低是它們！吃早午餐熱量比較低？營養師教你3點健康吃法

## 1. 文獻核心論點與背景
早餐店是台灣重要飲食文化，但往往隱藏著高熱量、劣質油脂與精緻糖。李依縉營養師整理出完整早餐店熱量清單，並探討「早午餐（Brunch）是否真能比分開吃兩餐省熱量」的迷思，強調透過低油、低鈉、避開加工品與原型蛋白質搭配，外食早餐完全可以在 **500 大卡內達到高營養均衡**。

---

## 2. 早餐店完整熱量大公開 (客觀數據庫)

### 2.1 飲料類熱量對照
* **奶精奶茶**：中杯 **300 kcal** / 大杯 **400 kcal**（早餐店熱量之王，由 100ml 奶精＋高糖紅茶製成）。
* **鮮奶茶**：中杯 **120 kcal** / 大杯 **200 kcal**（鮮奶 100ml 約 60 kcal，熱量僅奶精版一半）。
* **紅茶 (有糖)**：中杯 60 kcal / 大杯 85 kcal（中杯至少含 15g 砂糖）。
* **豆漿**：無糖中杯 **75 kcal**（含約 10g 優質蛋白質）/ 有糖中杯 120 kcal。
* **美式咖啡**：**0 kcal**。
* **拿鐵咖啡**：中杯 120 kcal / 大杯 160 kcal。
* **可可牛奶**：中杯 220 kcal / 大杯 310 kcal。
* **薏仁漿**：中杯 70 kcal / 大杯 100 kcal。

### 2.2 餐點類熱量對照
* **鐵板麵**：**500 kcal**（勾芡醬油糖與油麵，高碳水高鈉）。
* **煎荷包蛋**：**100 kcal**（含煎油）。
* **豬肉蛋三明治 / 漢堡**：**450 kcal**。
* **香雞蛋三明治 / 漢堡**：**500 kcal**（加工裹粉炸雞排）。
* **鮪魚蛋三明治 / 漢堡**：**300 kcal**（✅ **熱量最低且均衡首選**）。
* **培根蛋三明治 / 漢堡**：**400 kcal**。
* **原味蛋餅**：**250 kcal** / **起司蛋餅**：**300 kcal** / **玉米蛋餅**：**280 kcal**。
* **果醬吐司**：薄片 200 kcal / 厚片 280 kcal。
* **奶酥 / 巧克力 / 花生吐司**：薄片 250 kcal / 厚片 **350 kcal**。
* **蘿蔔糕**：**250 kcal**（兩片＋煎台吸油）。
* **煎餃 (5入)**：**400 kcal**（絞肉高脂與煎油）。
* **雞塊 (5入)**：**250 kcal** / **小熱狗 (3入)**：**180 kcal**。

## 3. 早午餐 (Brunch) 迷思深度解析
* **分開吃兩餐**：傳統早餐 (500~1000 kcal) + 商業便當午餐 (700 kcal) = **1200 ~ 1700 kcal**。
* **早午餐熱量真相**：
  * 若為「健康盤」（歐姆蛋、水煮嫩雞胸、大量生菜、無糖優格、堅果、少許酸種麵包）：約 **800 kcal**，確實低於分開吃的總和。
  * 若為「傳統美式拼盤」（炒蛋含奶油、焦脆培根、炸薯餅/薯條、德式熱狗、厚片法式吐司淋楓糖漿）：一餐即可暴衝至 **1500 kcal 以上**！並未達到節省熱量的效果。

---

## 4. 營養師健康吃 3 大黃金點餐法則
1. **低油、低鈉，分散油脂風險**：
   * 早餐主要油脂來自「煎台」與「炸物」。若點了蛋餅或蘿蔔糕，飲品**嚴禁再選奶精奶茶**，應搭配黑咖啡或無糖茶。
   * 請店家「少醬」或選擇「自行加醬」店家，避免鈉離子超標引起水腫與高血壓。
2. **避免加工製品，多選原型食物**：
   * 培根、火腿、熱狗、雞塊皆為超加工紅肉，具備高脂、高鈉及亞硝酸鹽疑慮。
   * 優先選新鮮雞腿排（去皮）、雞胸肉、水煮鮪魚。
3. **嚴控精緻糖**：
   * 遵照每日精緻糖總熱量 10% 限制，早晨堅決以無糖飲品為主。
