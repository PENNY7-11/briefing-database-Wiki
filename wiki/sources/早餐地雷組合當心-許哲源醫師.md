# 早餐地雷組合當心！醫曝「就是在吃油」 爆卡還吃不飽

## 1. 文獻核心論點與觀點
台灣傳統早餐品項繁多，但許多熱門品項（如燒餅油條、鐵板麵、蘿蔔糕、奶酥吐司）本質上是**「純碳水化合物化合物＋極高比例劣質油脂」**的聚合體。許哲源醫師指出，部分組合看似普通，但實質上**「基本上就是在吃油」**，造成「爆卡卻吃不飽」的生理窘境。

## 2. 傳統早餐店九大品項深度剖析

| 品項名稱 | 營養成分特性 | 熱量與油脂陷阱評估 | 醫師健康建議與改良方案 |
| :--- | :--- | :--- | :--- |
| **蛋餅** | 餅皮為澱粉，但含蛋 | 餅皮佔比適中，提供至少 1 顆蛋的優質蛋白 | ✅ **推薦品項**。建議加點「里肌豬排」增加蛋白質與飽足感。 |
| **三明治** | 吐司＋生菜＋半顆蛋＋夾料 | 夾料若是炸物、薯餅、火腿培根則油脂爆表；美乃滋為主要隱形油 | 避開炸肉排與加工品，選豬里肌或水煮鮪魚，明確告知店家**少或去美乃滋**。 |
| **漢堡** | 麵包＋夾肉＋蛋 | 漢堡包份量比三明治多（雙面麵包澱粉量大） | 避開炸雞排、香雞排，慎防高油重組肉排。 |
| **生菜沙拉** | 蔬菜纖維為主 | 若附千島醬熱量極高；和風醬較輕盈 | ✅ **可多攝取**。醬料建議選用低卡和風醬，或僅沾取少量。 |
| **蘿蔔糕** | 蘿蔔絲＋再來米漿 | 主成分為精緻澱粉；在煎台高溫吸附大量煎油 | 參閱 [[高溫油脂吸附與煎台熱量炸彈]]，吸油率驚人，減脂期建議少吃或改為蒸煮。 |
| **鐵板麵** | 油麵＋濃稠勾芡醬＋玉米粒 | ❌ **最危險地雷**！份量熱量高達 **600 kcal**，全是澱粉＋糖油芡汁 | 強烈建議避免！缺乏蛋白質與蔬菜，吃完後血糖巨幅震盪。 |
| **果醬/抹醬吐司** | 兩片白吐司＋抹醬 | 兩片吐司等同一碗白飯；香蒜、奶酥、花生醬熱量高達 200~400 kcal | 缺乏蛋白質，高糖高飽和脂肪，引發餐後嗜睡。 |
| **燒餅油條** | 酥油麵糰＋深層油炸麵糰 | ❌ **吃油之王**！一份 400~500 kcal，燒餅揉入大量酥油，油條吸滿油脂 | 實質「油包油」，飽足感低且反式脂肪風險高。 |
| **早餐店飲料** | 大多為全糖紅茶、奶精奶茶 | 含糖量高、奶精含大量反式/飽和脂肪 | 參閱 [[外食早餐飲品降階減糖法]]，建議以白開水、無糖豆漿或鮮奶為主。 |

## 3. 醫師總結之健康早餐選擇原則
1. **多吃優質蛋白**：優先挑選雞蛋、新鮮肉類（里肌豬排、雞胸肉）、豆漿。
2. **避開高危三元素**：嚴格避開精緻純澱粉（鐵板麵）、油炸物（薯餅、油條）、高油脂沾抹醬。
3. **主動客製化點餐**：利用「去醬、加蛋、加肉、無糖」技巧，降低外食環境的不確定性。
