# 你早餐吃對了嗎？由鄧雯心醫師來公開地雷早餐大破解！

## 1. 文獻核心論點與背景
許多人陷入「要不要吃早餐」的迷思，但鄧雯心醫師指出，**「亂吃早餐比不吃早餐更傷身」**。不當的早餐選擇（高精緻碳水、隱形油脂、含糖飲料）會造成血糖驟升驟降、過度刺激胰島素分泌，並引發飢餓感惡性循環。

### 特別適用族群
1. 心理或生理習慣必須吃早餐者（不吃會胃痛、頭痛）。
2. 具備血糖波動、三高、脂肪肝或 [[胰島素阻抗與早餐升糖反應|胰島素阻抗]] 族群。
3. 吃得少或自認清淡卻始終無法減脂者。
4. 無法大幅調整中晚餐、坐式生活/缺乏運動的上班族。

## 3. 鄧醫師早餐四大黃金法則

1. **減少 (Subtract)**：
   - 減少添加糖（飲料、麵包、沙拉淋醬、抹醬）。
   - 減少低營養價值油脂（加工肉品、炸物、奶精、氫化油，參閱 [[隱藏油脂與低營養價值脂肪]]）。
   - 減少超加工食品與精緻澱粉。
2. **增加 (Add)**：
   - 增加優質蛋白質（蛋、無糖豆漿、豆腐、無糖優格、瘦肉）。
   - 增加膳食纖維（未精製全穀雜糧、蔬菜）。
   - 增加營養密度與食物多樣性。
3. **注意比例與份量 (Ratio & Portion)**：
   - 落實 [[外食族211晨間餐盤實踐法]]（蔬菜：蛋白質：澱粉 = 2 : 1 : 1）。
   - 講求「吃飽吃巧不吃撐」。
4. **進食順序 (Sequence)**：
   - 採用 [[水肉菜飯果進食順序法]]，避開「混在一起、夾在一起」的加工物，藉此平抑餐後胰島素波動。
