# 500大卡黃金早餐公式

## 公式設計邏輯
根據國人每日能量消耗（TDEE）與減脂熱量赤字模型，將早餐總熱量控制在 **$400 \sim 500\text{ kcal}$** 是兼顧能量代謝與減肥效益的最佳區間。

$$\text{500大卡黃金早餐} = \text{複合低GI碳水 (40\%)} + \text{優質蛋白質 } \ge 20\text{g (30\%)} + \text{良質脂肪 (30\%)} + \text{無糖高纖飲品}$$

## 模組化組合積木
| 模組 | 角色 | 推薦選項 | 熱量/蛋白質估計 |
| :--- | :--- | :--- | :--- |
| **模組 A** | 複合碳水基底 | 全麥吐司2片、地瓜1條、一般薄蛋餅皮 | $150 \sim 200\text{ kcal}$ / $4\sim 6\text{g P}$ |
| **模組 B** | 主力優質蛋白質 | 原塊煎豬里肌肉片、水煮鮪魚、荷包蛋/水煮蛋2顆 | $150 \sim 180\text{ kcal}$ / $15\sim 20\text{g P}$ |
| **模組 C** | 纖維與水分補充 | 生菜、番茄片、小黃瓜絲（夾於吐司中） | $15 \sim 30\text{ kcal}$ / $1\text{g P}$ |
| **模組 D** | 液體代謝推進劑 | [[無糖高纖豆漿]]（350~500ml）、大杯黑咖啡 | $0 \sim 150\text{ kcal}$ / $0\sim 15\text{g P}$ |

## 實務搭配範例
* 經典組：[[豬排里肌蛋吐司]]（去醬）+ [[無糖高纖豆漿]] $\approx 420\text{ kcal}$，蛋白質高達 $29\text{g}$。
* 蛋餅組：[[原味蛋餅]] + 額外荷包蛋 + 無糖黑咖啡 $\approx 355\text{ kcal}$，蛋白質約 $17\text{g}$。
